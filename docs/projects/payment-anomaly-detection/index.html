Payment Transaction Anomaly Detection

An end-to-end exploration of payment fraud detection using statistical analysis, anomaly detection and supervised learning.

In progressFraud DetectionStatisticsIsolation ForestScikit-learn

Project overview

Build and evaluate a transaction anomaly detection workflow using the ULB Credit Card Fraud Detection dataset. The project moves from exploratory statistics to model comparison, threshold analysis and a production-oriented architecture.

Dataset / inputs

ULB Credit Card Fraud Detection (Kaggle)

Open dataset ↗

Methods and experiments

  • Feature distribution analysis
  • Class-imbalance assessment
  • Statistical thresholds (Z-score / IQR)
  • Isolation Forest
  • Supervised classification baseline
  • Precision-recall and threshold analysis

Current status and next step

In progress — project notes will be expanded as the work progresses.

Next: Load the dataset, inspect schema and class balance, then profile transaction amount and time features.

Notes and limitations

The dataset contains anonymized PCA components (V1–V28) and covers a short time window. It is useful for imbalance and detection experiments, but does not support rich customer-level behavioral or long-term seasonality analysis.
