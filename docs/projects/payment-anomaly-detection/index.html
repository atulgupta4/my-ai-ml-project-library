Payment Transaction Anomaly Detection.

An end-to-end investigation of highly imbalanced credit card transactions, comparing supervised learning approaches and examining how model thresholds affect fraud detection and false-alert volume.

ULB Credit Card Fraud Dataset XGBoost Scikit-learn SHAP

Project at a glance

The objective is to identify fraudulent transactions in a dataset where legitimate activity greatly outnumbers fraud. The work covers data exploration, baseline modeling, class-imbalance strategies, threshold selection, model comparison and post-hoc explainability.

Model experiments and results

Multiple approaches were explored to understand the impact of class imbalance and decision thresholds. The final XGBoost test evaluation used a 0.70 threshold selected during validation.

Explainability

Feature importance and SHAP summary analysis were used to inspect which anonymized input features influence the fitted XGBoost model's predictions. These explanations describe model behavior; they do not establish causal relationships.

The notebook contains the SHAP analysis and generated visualizations. Additional static result images can be added here when exported from the notebook.

From model experiments to production considerations.

A production deployment would require reliable online features, transaction velocity and customer or merchant context, model serving, operational monitoring, confirmed-outcome feedback and a governed retraining process. These are proposed next steps beyond the notebook.
