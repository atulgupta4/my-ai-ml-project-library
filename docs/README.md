# My AI/ML Project Library

Dark, responsive, static project showcase website.

## Preview
Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Create a **public** GitHub repository, e.g. `my-ai-ml-project-library`.
2. Upload the contents of this folder to the repository root. Ensure `index.html` is at the root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment. GitHub Pages will show the public site URL in the Pages settings.

A project site URL usually looks like:
`https://YOUR-USERNAME.github.io/my-ai-ml-project-library/`

## Update the website
- Edit project cards in root `index.html`.
- Edit project detail pages under `projects/<project-name>/index.html`.
- Shared styles are in `assets/style.css`.
- Search and filters are in `assets/script.js`.

## Safety
This is a static showcase, not a model-serving application. Do not commit payment card data, credentials, API keys, private notebooks, or other sensitive information. Published Pages sites are public.
